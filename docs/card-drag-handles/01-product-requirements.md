# 卡片拖拽手柄产品需求

## 文档关系

本文定义已批准的产品范围与验收标准。交互细节见[交互规格](02-ux-interaction-spec.md)，实现边界见[技术设计](03-technical-design.md)，落地顺序和测试见[实施计划](04-implementation-plan.md)。

## 背景与目标

当前主界面通过标题栏的“排序”按钮进入排序模式。该模式会关闭卡片长按菜单，以避免长按拖拽与菜单手势冲突。卡片本身仍承担点击分享这一高频操作。

本功能改为在可排序卡片上显示明确的拖拽手柄。用户仅从手柄开始拖动，卡片其余区域继续用于分享和长按菜单。排序结果继续写入现有数据库排序字段，不改变表结构、同步清单或桌面端兼容规则。

## 范围

### 包含

- 移除主界面标题栏的 `btn_sort` 及其排序模式状态 `sortEnabled`。
- 在满足排序条件的每张表情卡片上显示可触摸的拖拽手柄。
- 仅由手柄开始拖拽，支持网格中的上下左右换位。
- 保持全局视图调用 `reorderMemes`，真实分组视图调用 `reorderCollectionMembers`。
- 保持卡片点击分享、使用记录与根卡片长按上下文菜单。

### 不包含

- 不改变数据库 schema、云端清单、桌面端代码或排序数据格式。
- 不增加排序开关、排序提示、撤销功能、跨分组移动或虚拟分组排序。
- 不改变分享流程、长按菜单项目、分组过滤、搜索结果或动图播放逻辑。

## 需求

| ID | 已批准需求 |
|---|---|
| REQ-CDH-001 | 系统必须移除标题栏的 `btn_sort` 和 `sortEnabled`，排序不再依赖模式切换。 |
| REQ-CDH-002 | 系统必须仅在以下条件同时满足时显示并启用卡片拖拽手柄：搜索关键词为空，当前为全局视图或正数真实分组，且当前网格至少有 2 张卡片。 |
| REQ-CDH-003 | 搜索结果及虚拟分组收藏夹 `-2`、最近使用 `-3`、未分类 `-4` 必须隐藏拖拽手柄，且不得重排。 |
| REQ-CDH-004 | 拖拽必须只由显式手柄启动。卡片根视图的点击必须继续分享，根视图长按必须继续打开上下文菜单。 |
| REQ-CDH-005 | 在全局视图完成拖拽后，系统必须按适配器当前 ID 顺序调用 `reorderMemes` 持久化。 |
| REQ-CDH-006 | 在正数真实分组完成拖拽后，系统必须按适配器当前 ID 顺序调用 `reorderCollectionMembers(collectionId, ids)` 持久化。 |
| REQ-CDH-007 | 手柄必须有本地化无障碍描述，触摸区域约为 48dp，并位于卡片左上区域，避开右上角动图或隐写角标及底部名称遮罩。 |

## 验收标准

| ID | 对应需求 | 可观察结果 |
|---|---|---|
| AC-CDH-001 | REQ-CDH-001 | 主界面标题栏不再显示排序按钮，代码不再维护 `sortEnabled`。 |
| AC-CDH-002 | REQ-CDH-002 | 空搜索的全局视图和成员数不少于 2 的正数真实分组显示手柄，可从手柄拖动卡片换位。 |
| AC-CDH-003 | REQ-CDH-002 | 当前网格只有 0 或 1 张卡片时不显示手柄，也不能开始拖拽。 |
| AC-CDH-004 | REQ-CDH-003 | 输入任意搜索关键词后，以及查看收藏夹、最近使用或未分类时，手柄不显示且长按不触发排序。 |
| AC-CDH-005 | REQ-CDH-004 | 在可排序视图中，点击手柄以外的卡片区域仍进入系统分享流程，长按根卡片仍显示原上下文菜单。 |
| AC-CDH-006 | REQ-CDH-005 | 全局视图拖拽后重新加载数据，卡片顺序保持为拖拽结果。 |
| AC-CDH-007 | REQ-CDH-006 | 正数真实分组拖拽后重新加载该分组，成员顺序保持为拖拽结果，且不要求改变全局顺序。 |
| AC-CDH-008 | REQ-CDH-007 | 辅助功能可读到本地化手柄名称；手柄触摸区域约 48dp，视觉位置不遮挡右上角角标或底部名称。 |
